Minimarket Web API Backend - Беккенд сервер для интернет магазина 
Технологии
Язык: С# 12
Среда выполнения: .NET 8
ORM: Entity Framework Core
Базы данных: MSSQL
Аутентификация: JWT
Роли для пользователей: admin, user

Роли:
Администратор:
Добавление новых товаров
Редактирование товаров
Пользователь:
Просмотр списка товаров
Фильтрация товаров(по названию и цене)
Добавление товаров в корзину
Удаление товаров из корзины
Оформление заказа

Работа с товарами
Каждый товар имееть следующие поля:
ID(автоматически)
Название
Описание
Цена
Изображение(url)
Дата создания

Корзина и заказы
Пользователь может добавлять и удалять товары из корзины
Корзина хранится на сервере и привязана к пользователю
Пользовательможет оформить заказ и в этом сдучае корзина очищается, создается запись в таблиуе заказов

Проект построен по классической многослоной архитектуре (Controller-Service-Repository), имеет систему защиты по ролям.
Архитектура и структура проекта
Код разделен на слои, чтоб предотвращать доблирование логки и делает проект расшираемым:
1. Controllers- отвечают только за роутинг, прием HTTP-запросов и возврат унифицированных ответов через класс APIResponse. Прямой доступ к базе данных из них исключен.
2. Services (бизнес-логика)- место где происходит все вычисления, проверки, счет цен и сохранение данных.
3. Models- модели базы данных, связанные между собой внешними ключами.
4. DTOs- бланки для безопасного обмена данными между фронтендом и бэкендом.

Возможности и реализованные методы
1.AuthController- авторизация и доступ
POST /api/auth/register- регистрация пользователей с указанием роли. Пароли хешируются
POST /api/auth/login- аутентификация пользователя. Сервер генерирует и возвращает JWT-токен.
2. ProductsController- витрина товаров
GET /api/products- метод каталога с фильтрацией по названию и диапазону цен.
3. AdminProductsController- управление товаров для админа
POST /api/admin/products- создание новой карточки товара с авто генерацией даты создания на сервере.
PUT /api/admin/products/{id}- полное обновление информации о товаре.
DELETE /api/admin/products/{id}-удаление товара из базы данных.
4. CartController- корзина покупателя
POST /api/cart/add- добавление товара в корзину
DELETE /api/cart/remove/{productId}- удаление товара из корзины
GET /api/cart- просмотр содержимого корзины
POST /api/cart/checkout- оформление заказа. Считает общую сумму заказа, создает чек в таблицах Orders и OrderItems, фиксирует цены на момент покупки и очищает корзину покупателя.

Структура база данных
1. User- хранит аккаунты, хеши паролей, роли и дату регистрации
2. Product- хранит карточки товаров
3. CartItem- таблица корзины, связана внешними ключами с User и Product
4. Order- шапка оформленного заказа. Содержит итоговую сумму покупки и связь с покупателем
5. OrderItem- состав чека заказа, хранит стоимость товара на момент покупки, защищая систему от изменение цен в будущем.
